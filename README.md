# 小红书画布 · 自由排版

把文字、图片和图形放上画布，像编辑一页 PPT 一样自由排版。原来的固定版式生成器已改为可编辑的多页画布，原有十种模板均可作为起点。

纯前端静态网站，无账号、服务器、上传接口或云同步。Fabric.js 和 ZIP 导出库随项目保存，不依赖在线 CDN。

## 使用

打开 `index.html` 即可编辑；日常使用建议通过 GitHub Pages 或本地 HTTP 服务打开，浏览器草稿存储更稳定。

- 左侧添加标题、正文、图片、矩形、圆角矩形、圆形和线条，也可拖入或粘贴图片。
- 在画布上拖动元素，拉动角点缩放，顶部手柄旋转。文字框两侧调整宽度、自动换行，高度随内容增长。
- 双击文字或选中后点击「编辑文字」。选中部分文字后，可单独设置字体、字号、颜色、加粗、斜体和下划线。
- Shift 点选或框选多个元素，进行组合、拆分、对齐、复制或整体移动。拖动时提供边缘和中心吸附；按 Alt 临时跳过吸附。
- 右侧六个对齐按钮直接显示在设置顶部，无需展开菜单；悬停或键盘聚焦可查看名称。「位置与大小」点击标题展开，本次会话保留展开状态。顶部元素操作固定，下面设置独立滚动。调整位置、大小、透明度和图层顺序；锁定后从右侧图层或属性解锁。
- 右侧“属性／图层”页签分开管理工具与图层；属性采用标签在上、控件在下的舒展排列，常用操作使用图标，内容较多时可滚动。分组旁的 ⓘ 在电脑上悬停或键盘聚焦显示说明，手机轻点查看或关闭，Esc 关闭提示。
- 图片支持比例裁剪、取景位置、放大和水平翻转。裁剪保留原图，可再次调整。
- 背景支持纯色、渐变、方格、点阵、纸张纹理和本地图片。更换背景不影响已有元素。
- 模板作为新页插入，避免覆盖当前作品。支持新建、复制、删除和重新排序页面。
- 导出当前页 PNG，或将全部页面打包为 ZIP；支持原尺寸和 2 倍尺寸。导出不包含选中框和辅助线。

### 画布视图

桌面工作区缩减工具栏占用，让画布显示更大。「专注编辑」隐藏左右侧栏与页面栏，再次点击恢复原有页签和折叠状态。手机保留底部面板操作。

缩放菜单提供适应窗口、50%、75%、100%、150%。手动缩放后，窗口大小变化保留比例；选择「适应窗口」恢复自动适配。缩放、专注与折叠设置只影响界面，不改变作品、导出尺寸或撤销记录。

### 电脑快捷键

| 操作 | 快捷键 |
| --- | --- |
| 撤销 / 重做 | Ctrl / ⌘ Z；Ctrl / ⌘ Shift Z |
| 多选 / 全选 | Shift 点选；Ctrl / ⌘ A |
| 复制 / 粘贴元素 | Ctrl / ⌘ C；Ctrl / ⌘ V |
| 快速复制 | Ctrl / ⌘ D |
| 组合 / 拆分 | Ctrl / ⌘ G；Ctrl / ⌘ Shift G |
| 微调位置 | 方向键 1 px；Shift + 方向键 10 px |
| 删除元素 | Delete / Backspace |
| 缩放视图 | Ctrl / ⌘ + 滚轮；顶部 − / ＋ |
| 取消选择 | Esc |

输入文字时保留文本输入框的常规编辑快捷键。

### 手机

底部切换元素、模板、背景与属性面板。「多选」开启后依次点选元素，再到属性面板组合或对齐。单指拖动元素，双指缩放和移动画布视图；选中文字后可使用「编辑文字」按钮调用键盘。

底部工具面板默认半屏打开。再次点击同一个底部入口收起面板，点击不同入口切换内容并保留高度。拖动顶部把手或标题区可上拉展开、下拉回半屏，再下拉关闭；点击把手也可切换高度。内容区独立滚动，轻点面板外部或关闭按钮可收起。系统减少动态效果设置会关闭开合动画。页面复制、删除和排序使用图标按钮，手机将缩略图和操作栏分成两行。

已进行 Chromium 移动端模拟测试；不同手机输入法和 Safari 的触控体验仍建议真机验收。

## 本地自动保存

作品及图片自动存入当前浏览器的 IndexedDB。刷新或重新打开同一网址，可恢复最近一次保存的草稿。

- 不跨设备、不同浏览器或不同网址同步，也不发送到服务器。
- 清除网站数据、浏览器回收存储或无痕会话结束可能删除草稿，重要作品请及时导出图片。
- 存储失败会提示先导出。撤销记录仅在当前会话保留，最多 50 步，并按内存预算缩减。
- 同时编辑多个浏览器标签可能互相覆盖草稿，建议只打开一个编辑页面。
- 图片支持 PNG、JPG、WebP，单张不超过 30 MB；超过 4096 像素的图片会按比例缩小后保存。
- 画布尺寸更改保留元素位置和尺寸，可能需要手动重新排版。

## GitHub Pages 部署

这是可直接发布的静态目录，不需要安装 Node.js 或运行构建。

1. 将代码推送到 GitHub 仓库的 `main` 分支。
2. 打开仓库 **Settings → Pages**，Source 选择 **Deploy from a branch**。
3. 选择 **main / (root)** 并保存。
4. 等待 GitHub Pages 部署完成，访问 [小红书画布](https://andycr0w.github.io/tool_xiaohongshu-card-generator/)。

如果仓库已经按 main 分支根目录发布，推送后会自动更新。所有应用资源均使用相对路径，适配仓库子路径；`.nojekyll` 用于静态发布。具体发布配置见 [GitHub 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 开发与验证

`package.json` 仅用于浏览器测试，线上编辑器不使用 npm 依赖。

```sh
npm install
npx playwright install chromium
npm test
```

使用已安装的 Edge 时，设置环境变量 `BROWSER_CHANNEL=msedge` 后运行测试。测试自动启动本地服务，并在仓库子路径下验证页面加载、富文本、撤销重做、组合坐标、图片裁剪、草稿恢复、导出内容、模板以及手机布局。截图和导出验证文件保存在已忽略的 `test-results/`。

主要文件：

- `index.html`、`editor.css`：桌面工作区和手机底部面板。
- `toolbar.css`、`toolbar.js`：界面文字、顶部 Home 导航、本地 SVG 图标与操作反馈；支持减少动态效果。
- `panels.css`、`panels.js`：属性页签与舒展布局、提示浮层样式、手机半屏／展开面板及可中断手势动画。
- `editor.js`：画布交互、多页文档、历史记录、IndexedDB、图片与 ZIP 导出。
- `templates.js`：十种模板的独立可编辑元素。
- `vendor/`：Fabric.js 6.9.0、fflate 0.8.2 及各自许可证。

`npm run test:toolbar` 单独验证工具栏图标状态、键盘操作、失败反馈、文字选区和减少动态效果，并生成不同像素密度及窄屏截图。125% / 150% 放大检查通过等效 CSS 视口与像素比模拟桌面浏览器缩放，不替代不同操作系统上的真机字体观感检查。

`npm run test:panels` 验证属性布局与低高度视口的滚动可达性、ⓘ 悬停／轻点提示与选区、页面排序边界及删除确认／取消／撤销、底部入口重复点击、面板拖动／取消／快速切换、焦点恢复与减少动态效果。软键盘布局通过可见视口缩小模拟，仍建议在真实手机上检查输入法体验。

## Git 文件管理

应提交：网站源码、`tests/` 测试源码、`vendor/` 运行时依赖和许可证、网站图标、`package.json`、生成后的依赖锁文件，以及 `.gitignore` 本身。

不应提交：依赖安装目录、缓存、日志、测试报告、截图和导出验证文件。本地测试产物统一放在 `test-results/`，临时文件放在根目录 `tmp/` 或 `temp/`。不要用 `*.png` 或 `*.zip` 统一忽略正式素材。`.env` 及其变体被忽略，`.env.example` 保留。

提交前可只读检查：

```sh
git check-ignore -v test-results/desktop.png node_modules/example/index.js .cache/example .env
git ls-files -ci --exclude-standard
git add --dry-run .
```

第二条应没有输出；第三条只预览候选文件，不实际暂存。`.gitignore` 不影响已经跟踪的文件，也不能阻止强制添加。若未来发现产物已经被跟踪，需要针对确认的文件单独取消跟踪，保留本地副本；不要批量重建整个 Git 索引。本项目没有新增 Git hook、CI/CD 或自动发布流程。

`npm run test:workspace` 验证目标窗口尺寸、画布可用空间、视图状态与草稿隔离、折叠设置、编辑文字入口和手机操作。截图同样写入 `test-results/`。
