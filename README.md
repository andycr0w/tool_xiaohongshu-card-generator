# 小红书画布

一个可自由排版的小红书图片编辑器。支持多页画布、文字、图片、图形、模板和背景设置。

## 使用

直接打开 `https://andycr0w.github.io/tool_xiaohongshu-card-generator/` 即可使用。

- 从左侧添加文字、图片和图形，也可以拖入或粘贴图片。
- 在画布上拖动、缩放、旋转元素；双击文字即可编辑。
- 支持多选、组合、对齐、调整图层和图片裁剪。
- 可新建、复制、删除和排序页面，也可将当前页导出为 PNG，或将全部页面导出为 ZIP。
- 作品会自动保存在当前浏览器中，重要内容请及时导出备份。

### 电脑快捷键

| 操作 | 快捷键 |
| --- | --- |
| 撤销 / 重做 | Ctrl / ⌘ Z；Ctrl / ⌘ Shift Z |
| 多选 / 全选 | Shift 点选；Ctrl / ⌘ A |
| 复制 / 粘贴元素 | Ctrl / ⌘ C；Ctrl / ⌘ V |
| 快速复制 | Ctrl / ⌘ D |
| 组合 / 拆分 | Ctrl / ⌘ G；Ctrl / ⌘ Shift G |
| 微调位置 | 方向键 1 px；Shift + 方向键 10 px |
| 删除元素 | Delete / Backspace |
| 缩放视图 | Ctrl / ⌘ + 滚轮；顶部 − / ＋ |
| 取消选择 | Esc |

输入文字时，可继续使用文本输入框的常规编辑快捷键。
